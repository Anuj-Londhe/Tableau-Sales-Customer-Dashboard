A complete Tableau project built using a structured user story. It includes two dashboards designed to analyze sales performance and customer behavior. This project covers requirement analysis, data modeling, KPI creation, trend development, and interactive dashboard design.

---

## 🚀 Project Overview

This project consists of two interactive Tableau dashboards:

### 1. Sales Performance Dashboard
- YoY comparison for Sales, Profit, and Quantity  
- Monthly Sales & Profit trends  
- Product subcategory comparisons  
- Weekly Sales & Profit with above/below average highlights  

### 2. Customer Insights Dashboard
- Customer KPI summary  
- Monthly customer trends  
- Customer distribution by order count  
- Top 10 customers by profit with rank and order details
